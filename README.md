# 📊 Vendor Performance Analysis Dashboard

An interactive Power BI dashboard designed to analyze vendor and product performance using sales, revenue, pricing, inventory, and brand-level metrics.

## 📌 Project Overview

This project focuses on analyzing vendor performance and product-related data to identify patterns in sales, revenue, pricing, inventory distribution, and brand performance.

The dashboard converts raw business data into interactive KPIs and visualizations that make it easier to understand vendor and product performance.

## 🎯 Objectives

- Analyze product-wise sales performance
- Compare revenue across cities
- Understand product inventory distribution by size
- Analyze the relationship between price and orders
- Identify brands with the highest orders and sales
- Explore product and vendor performance using interactive filters

## 🛠️ Tools & Technologies

- **Power BI** – Dashboard development and visualization
- **Power Query** – Data cleaning and transformation
- **DAX** – Measures and calculated metrics
- **Excel / CSV** – Data source
